# Getting help

| You want to... | Go to |
|---|---|
| Learn how to install, set up and use MonkeyMode | The [user guide](docs/GUIDE.md) (section 9 is the FAQ) and [onboarding](docs/ONBOARDING.md) |
| Ask a question | [Discussions → Q&A](https://github.com/AidenKim923/MonkeyMode/discussions/categories/q-a) |
| Talk through an idea | [Discussions → Ideas](https://github.com/AidenKim923/MonkeyMode/discussions/categories/ideas) |
| Show what you made | [Discussions → Show and tell](https://github.com/AidenKim923/MonkeyMode/discussions/categories/show-and-tell) |
| Report a bug, propose a skill or guardrail rule, fix an adapter or the docs | [Open an issue](https://github.com/AidenKim923/MonkeyMode/issues/new/choose) and pick the matching form |
| Report a security vulnerability | Privately, as described in [SECURITY.md](SECURITY.md) |
| Report a Code of Conduct problem | See [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md#enforcement) |

Inside a project, `/mm-help` looks at what exists and tells you the next step.

MonkeyMode is maintained by volunteers. There is no paid support; answers come from the community and maintainers when they can. Problems with Claude Code, Codex or a game engine itself belong with those projects.
